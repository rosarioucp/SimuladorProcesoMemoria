Este repositorio contiene una aplicación desarrollada en TypeScript que implementa un Simulador de Procesos y Memoria, diseñado bajo principios de Programación Orientada a Objetos, cuenta con características como:
-Simulación de Procesos: Gestión de estados, ciclo de vida y planificación de procesos.
-Gestión de Memoria: Simulación de asignación y administración de espacio de memoria.
-Pruebas Unitarias: Cobertura de código robusta mediante suites de pruebas automatizadas.
Los pasos para instalar son:
Ejecutar en la terminal 
1- Clonar el repositorio: git clone 
2-Instalar dependencias: npm install
3-Correr los tests: npm test
4-Ver cobertura: npm run coverage
